# ATMOS-VIGIL — Capacitor Android APK source

This directory ships the two native Android plugins (Kotlin) that give the
self-hosted `.APK` its real hardware sensors:

- `BarometerThermoPlugin.kt` — MEMS pressure (`Sensor.TYPE_PRESSURE`), ambient
  temperature (`Sensor.TYPE_AMBIENT_TEMPERATURE`) and relative humidity
  (`Sensor.TYPE_RELATIVE_HUMIDITY`) — the native mirror of the web
  `Web Sensor API` code path.
- `AeroAcousticAnemometerPlugin.kt` — raw uncompressed microphone PCM
  (`AudioRecord`, 16-bit mono, 44.1 kHz) analyzed as sub-bass turbulence
  (20–250 Hz) with the cube-root wind law `mph ∝ RMS^(1/3)` — the native
  mirror of the web audio engine.

The plugin Java classes live in
`android/app/src/main/java/com/atmosvigil/meteo/`. The Kotlin plugin registration
template lives in `android/capacitor/MainActivity.kt` — the CI pipeline copies
the template into the `android/` project as it is generated by
`npx cap add android` (the webDir is `build/`, built by `npm run build`).

The full automated pipeline is `.github/workflows/build-and-bundle-apk.yml`.
